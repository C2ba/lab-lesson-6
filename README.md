# lab-lesson-6

Our program takes input from the user and assigns it to a variable labeled "name". It then takes two other inputs from the user, "text_input" and "word_modifier". The former takes a phrase of any length and searches for the latter. With this information, the program then counts how many times the target word occured in the phrase, and replaces the word with "[REDACTED]". Finally, the user's "text_input", "word_modifier", if the "text_input" was in the text at all (and if so how many times), and the modified text are printed in a neatly formatted manner.
